# Страница статусов «Право выбора»

Витрина для заказчиков: одна постоянная ссылка, открывается без аккаунта и без VPN.

## Как это устроено

1. **Пульт** — Google Таблица «Право выбора — пульт статусов». Строка на ролик, колонка «Этап».
2. **Робот** — `.github/workflows/update.yml`, раз в час запускает `build.py`.
3. **Сборщик** — `build.py` читает таблицу и перезаписывает `data.json`.
4. **Витрина** — `index.html` показывает `data.json`. Ссылка на неё уходит заказчикам.

Правите этап в таблице — через час страница обновляется сама. Ничего заливать не нужно.

## Что правится руками

- `waiting.json` — блок «Ждём от вас» наверху страницы. Меняется редко.
- Допустимые значения колонки «Этап»: Сценарий готов · Снято · Монтаж · Ждём вашего слова · Принято · Опубликовано.
  Всё остальное робот покажет как «Сценарий готов» и напишет об этом в логе.

## Разовая настройка

1. Залить файлы в репозиторий.
2. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Открыть таблицу-пульт → Настройки доступа → «Все, у кого есть ссылка» → Читатель.
4. Actions → «Обновить статусы» → Run workflow — проверить, что робот дошёл до конца.
